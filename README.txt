## 🚀 Sobre o Projeto

A **IviInvest** é uma plataforma de apoio à decisão que utiliza **Inteligência Artificial** para analisar o perfil do investidor e sugerir estratégias personalizadas de aplicação financeira.  

### ✨ Principais objetivos:
- Oferecer recomendações inteligentes com base no perfil e objetivos do usuário.  
- Integrar dados do mercado em tempo real.  
- Promover uma experiência interativa e educativa sobre investimentos.
